 🎵 MusicStream - Tienda de Música Digital

MusicStream es una plataforma web moderna diseñada para la exploración, reproducción y compra de álbumes digitales. Este proyecto fue construido siguiendo un flujo de trabajo profesional de Git, con una interfaz oscura (Dark Mode) inspirada en las mejores aplicaciones de streaming actuales.



 Características principales
Tienda (Storefront): Exploración de álbumes por categorías con un diseño de tarjetas limpio.
Vista de Detalle: Información técnica del álbum (formato, año, género) y lista de canciones (Tracklist).
Reproductor Interactivo: Barra de música funcional con controles de reproducción y sonido real mediante etiquetas nativas de HTML5.
Carrito de Compras: Gestión de ítems con ajuste de cantidades y cálculo de totales.
Flujo de Pago Completo: Pasarela de pago simulada y pantalla de confirmación de compra exitosa.

Tecnologías utilizadas
* HTML5: Estructura semántica para todos los módulos.
* CSS3: Diseño responsivo, Flexbox, CSS Grid y efectos de iluminación (Glow effects).
* Git & GitHub: Control de versiones mediante el uso de ramas (`feature`, `develop`, `main`).
